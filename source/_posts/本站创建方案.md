**<span style="color: #FF5733;">此文简要记录了该网站的创立过程</span>**

# <span style="color: #71faff;">技术选型与基础搭建</span>
由于本人懒于维护服务器并且只想高效地上线此网站（其实就是没钱），因此将项目托管于GitHub Pages，架构采用Hexo。基础架构与编写方案均采用Hexo的基本方法。
```bash
hexo init myblog
#创建新的文章
hexo new "title"
#创建新的页面
hexo new page "page_name"
#本地预览
hexo clean
hexo g
hexo s
```
采用Github云端生成实现自动化流程（即配置[Github Actions](https://github.com/features/actions)）
```bash
git add .
git commit -m "Action's description"
git push origin main
```
所有源码与资源包均位于仓库。

# <span style="color: #71faff;">主题替换与基础配置</span>
网站采用Hexo第三方开源主题butterfly，对于底层的加载优先级，配置如下：
加载顺序（后者覆盖前者）：
   _config.yml                             (Hexo架构的基本设置，优先于所有配置文件先行挂载)
   _config.butterfly.yml                   (主题优先级最高文件)
   themes/butterfly/_config.yml            (主题默认值)
   themes/butterfly/scripts/common/default_config.js  (内置值)

UV/PV统计均采用[busuanzi](https://www.busuanzi.cc/)。由于第三方网站负载原因，该数据可能并不会很快地在浏览当中显示，并且可能会被Adblock等广告拦截插件拦截。
访问统计的源码如下
```yml
busuanzi:
  site_uv: true    # 本站访客数
  site_pv: true    # 本站总浏览量
  page_pv: true    # 单篇文章浏览量

aside:
  card_webinfo:
    enable: true   # 侧边栏的卡片是否显示UV/PV
```

本站的评论系统采用waline，具体配置方法见[友链页](https://hissgle.github.io/link/)说明。

评论功能的后端服务器托管平台采用Vercel的Neon数据库。由于本数据托管平台需要科学上网，因此评论功能无法正常加载和使用是正常现象。数据库当中的sql配置文件如下

# <span style="color: #71faff;">功能扩展与个性定制</span>
Live2D 看板娘：通过butterfly第三方插件配置了miku，为日后接入FastAPI提供入口。

全站搜索：对比了本地搜索和 Algolia，最终建议采用本地搜索方案。

阅读进度条：因为butterfly主题无 reading_progress 功能，通过原生 JS + CSS 注入实现，并修复了“只在文章详情页显示”的 Pjax 兼容问题。
_config.butterfly.yml配置中inject注入如下
头部：
```yml
- <style>#reading-progress{position:fixed;top:0;left:0;width:0%;height:3px;background-color:#ff5733;z-index:99999;transition:width .1s ease;}</style>
```

底部：
```yml
- <script>(function(){var bar=document.getElementById('reading-progress')||document.createElement('div');bar.id='reading-progress';document.body.appendChild(bar);function update(){var post=document.getElementById('post');if(!post){bar.style.width='0%';bar.style.display='none';return}bar.style.display='block';var h=document.documentElement.scrollHeight-document.documentElement.clientHeight;var t=document.documentElement.scrollTop||document.body.scrollTop;if(h>0){bar.style.width=Math.min((t/h)*100,100)+'%'}else{bar.style.width='0%'}}update();window.addEventListener('scroll',update);document.addEventListener('pjax:complete',function(){bar=document.getElementById('reading-progress')||bar;update()})})();</script>
```

其他特效：配置了首页樱花飘落特效、左下角 APlayer 音乐播放器（被网易云 API 限制了所以只能随便找一首不会404的歌）。
