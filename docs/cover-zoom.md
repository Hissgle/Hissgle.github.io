# 点卡片进文章：封面放大铺满屏幕

点首页博文卡片的封面或标题时，把那张封面平滑放大到铺满整个屏幕，
底下的 Pjax 完成换页后，过渡层再「落」进文章页顶部的 banner，最后淡出。

## 文件与开关

| 位置 | 作用 |
| --- | --- |
| `source/js/cover-zoom.js` | 效果实现（单文件、无依赖） |
| `source/css/cover-zoom.css` | 过渡层静态样式（节点由脚本动态创建/移除） |
| `_config.butterfly.yml` 的 `inject.head` | 引入样式 |
| `_config.butterfly.yml` 的 `inject.bottom` | 引入脚本 |

关闭整个效果：注释掉 `inject.bottom` 里加载 `cover-zoom.js` 的那行即可
（样式留着无害）。

## 调参数

改 `source/js/cover-zoom.js` 顶部的 `CFG`：

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `GROW` | `380` | 封面放大到铺满的时长（ms） |
| `HOLD` | `90` | 铺满后至少停留的时长，留给 Pjax 完成（ms） |
| `SETTLE` | `260` | 收进文章 banner 的时长（ms） |
| `FADE` | `170` | 收尾淡出时长（ms） |
| `DIM` | `0.45` | 放大过程中页面变暗程度（0 ~ 1） |
| `SAFE_NO_NAV` | `3500` | 迟迟没有 Pjax 导航就放弃（ms） |
| `SAFE_NAV` | `9000` | 已有导航但迟迟没完成的兜底（ms） |

缓动曲线是同文件的 `GROW_EASE`（快进慢出）、`SETTLE_EASE`（平滑收拢）。

浏览器控制台调试：

```js
window.coverZoom.active()  // 是否正在过渡
window.coverZoom.abort()   // 立即中止并移除过渡层
```

## 生效范围与边界

- 只在**首页卡片**（`.recent-post-item`）上触发，且只认封面链接和标题链接；
  分类/标签/评论数等链接、以及归档页的小缩略图都不参与。
- 同源、无 `#` 锚点、左键、无修饰键（Ctrl/Cmd/Shift/Alt）才触发；
  系统开了「减弱动效」（`prefers-reduced-motion`）时完全禁用。
- 封面懒加载还没换进真图（`src` 还是 1px 占位图）时**直接普通跳转**，不做动画。

## 实现要点

- **起点精确**：过渡层先按封面 img 的实测矩形摆好、裁剪到封面区域
  （`clip-path: inset(... round ...)`，圆角只保留卡片外侧的角，如左卡保留左侧两角），
  再开始放大，所以点下去的一瞬间画面不跳。
  测量前会把卡片悬停倾斜（`card-tilt.js` 的 `--ct-rx/--ct-ry/--ct-lift`）归零，
  否则量到的是 3D 投影的包围盒，会比摆正的封面大几个百分点。
- **过渡层挂在 `document.body` 下**（在 Pjax 的 `#body-wrap` 之外），换页不会把它冲掉；
  变暗层 `#cz-dim` 铺满视口并接收点击，过渡期间页面上的其它点击都被挡住。
- **收尾条件**：文章页 `#page-header.post-bg` 的 `background-image` 与封面是同一张图
  （都是居中 `cover` 裁切，所以能无缝衔接）才收进 banner，否则直接淡出。
  本站文章都是 `cover` 与 `top_img` 同图，正常走「收进 banner」。
- **安全网**：两条 `SAFE_*` 定时器保证任何异常路径下过渡层都会淡出移除，
  不会把用户困在过渡层里；`rAF` 被暂停的环境（后台标签页）有定时器兜底启动。

## 清晰度

过渡层用的是封面原图（不是缩略图），但「铺满屏幕」会把图放大约
`视口宽 ÷ 图片宽` 倍，素材不够大就会糊；高分屏按设备像素算（再乘 DPR），更明显。

当前素材与放大倍率（1920 宽视口、DPR 1，封面见 `source/img/`）：

| 文件 | 像素宽 | 铺满时放大约 |
| --- | --- | --- |
| `cover1.jpg` | 636 | 3.0×（最糊） |
| `cover2~4.jpg` | 1259 | 1.5× |

想彻底解决就换素材：**封面换成 ≥ 2000px 宽**（1080p 够用）、
1440p 或高分屏建议 ≥ 2560px，JPEG 质量 78~82，单张控制在 300~600KB。
同一个文件也用于文章页顶部 banner，换完两处都清晰；卡片缩略图是缩小显示，不受影响，
封面又是懒加载（滚动到才请求），不会拖慢首屏。

脚本侧已做的补强：鼠标悬停卡片时提前 `img.decode()` 整张解码（每个地址一次，
未加载的卡片用 `data-lazy-src` 提前进缓存），放大起跑时位图就是全分辨率；
过渡层不加 `will-change` 等合成提示，保证放大过程按帧重绘，不拿低分辨率纹理拉伸。
