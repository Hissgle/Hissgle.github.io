Hissgle / 写作台

一套能长期收敛的设计语言

写作台是单用户的长文写作工具：安静、可读、只有一件事需要被强调——发布。 本规范把界面里散落的数值收敛成 14 组 token，任何新界面都从 token 出发，而不是从“差不多”出发。

14组 token
12档字号
9档圆角
4px间距基准
2主题（自动同步）

设计原则

01 / principles
P1

内容先于界面

正文用衬线、行高 1.9；界面控件一律让位，chrome 只保留必要的边界与分隔。

P2

一个强调色

橙色只给主行动与品牌标记。其余层级靠中性色的明度与字重区分，不靠加颜色。

P3

暖纸，不冷灰

底色带一点黄调，长时间写作不刺眼；深色主题保留同一套暖中性色阶。

P4

克制的动效

只有 120 / 160 / 240ms 三档，只做位移与透明度，不做弹跳式装饰。

动效

06 / motion
Token值用于
--dur-fast120ms悬停变色、工具条按钮
--dur-base160ms按钮、输入框、侧边栏条目
--dur-slow240ms抽屉、弹窗入场、Toast
--ease-standardcubic-bezier(.2,.8,.3,1)默认
--ease-outcubic-bezier(.16,1,.3,1)入场
--ease-springcubic-bezier(.2,.9,.3,1.1)仅弹窗，其余不用

位移上限 1px；缩放下限 0.985；不做旋转、不做无限循环（加载指示除外）。系统开启“减少动态效果”时全部降为 0.01ms。

使用规则

07 / rules

✓应该

  • 新组件先查 token，缺失时补 token 而不是写裸值。
  • 橙色只出现在主按钮、品牌标记和链接强调。
  • 破坏性操作用 --danger，不要复用橙色。
  • 深色反色区域用 --inverse-* 系列。

✗不要

  • 不要新增 13px / 18px / 26px 这类“临时数值”。
  • 不要用 rgba() 直接写描边，改用 border token。
  • 不要给次要按钮加阴影或渐变。
  • 不要在深色主题里手写颜色覆盖，token 已处理。

✓无障碍

  • 正文与背景对比度 ≥ 4.5:1，次要文字 ≥ 3:1。
  • 键盘焦点统一 2px --focus-color 外描边。
  • 可点击目标 ≥ 28×28，图标按钮 36×36。
  • 所有图标按钮必须有 aria-label。
